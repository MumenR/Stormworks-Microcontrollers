# Stormworks 砲弾運動モデルまとめ

更新日: 2026-08-19

## 1. 概要

Stormworks の砲弾運動は、弾道計算上は主に次の要素から構成される。

- 砲口初速
- 砲弾固有の速度減衰
- 高度依存の重力加速度
- 高度依存の気圧
- 水平方向の風
- 気圧と風速に比例する風加速度

特に重要なのは、**砲弾の速度減衰率は気圧に依存しない**一方で、**風による加速度は気圧に比例する**ことである。

したがって Stormworks の砲弾モデルでは、

\[
\text{速度減衰}
\]

と

\[
\text{風の影響}
\]

は別の物理効果として扱う必要がある。

---

## 2. 座標系

弾道計算では、ワールド座標を

\[
\mathbf r=
\begin{pmatrix}
x\\
y\\
z
\end{pmatrix}
\]

とする。

ここでは、

- \(x,y\): 水平方向
- \(z\): 高度方向、上向きを正

とする。

高度を

\[
h=z
\]

または海面高度を含む絶対高度として扱う。

風ベクトルは常に水平であり、

\[
\boxed{
\mathbf V_w=
\begin{pmatrix}
V_{wx}\\
V_{wy}\\
0
\end{pmatrix}
}
\]

である。

したがって、風そのものが直接与える鉛直加速度は存在しない。

---

## 3. 重力加速度

高度 \(h\) [m] における重力加速度の大きさは、

\[
\boxed{
g(h)
=
30\exp\left(
-\frac{1}{60}\frac{h}{1000}
\right)
}
\]

で表される。

整理すると、

\[
\boxed{
g(h)=30e^{-h/60000}
}
\]

である。

海面高度 \(h=0\) では、

\[
g(0)=30
\]

となる。

高度が上がるにつれて重力加速度は指数関数的に減少する。

重力加速度ベクトルは、

\[
\boxed{
\mathbf g(h)=
\begin{pmatrix}
0\\
0\\
-g(h)
\end{pmatrix}
}
\]

である。

### 3.1 高度による変化

代表例として、

\[
g(60000)=30e^{-1}\approx11.0
\]

となる。

すなわち高度 60 km では、海面高度の約 \(36.8\%\) まで重力が低下する。

### 3.2 tick 単位で扱う場合

上式の \(g(h)\) を \(\mathrm{m/s^2}\) として扱う場合、Stormworks の 60 tick/s 系で時間を tick 単位に変換するなら、

\[
\boxed{
g_{\mathrm{tick}}(h)
=
\frac{g(h)}{60^2}
=
\frac{30e^{-h/60000}}{3600}
}
\]

となる。

---

## 4. 気圧

高度 \(h\) [m] における気圧係数を \(\rho(h)\) とすると、

\[
\boxed{
\rho(h)
=
\frac{
\left(
\frac{44.33-h/1000}{11.89}
\right)^{5.256}
}{
1013
}
}
\]

で表される。

海面高度付近では、おおむね

\[
\rho(0)\approx1
\]

となるように正規化されている。

高度が上昇すると \(\rho(h)\) は急激に低下する。

---

## 5. 砲弾の速度減衰

砲弾には種類ごとに固有の減速率 \(K\) が存在する。

Stormworks の弾道モデルで重要なのは、

\[
\boxed{
K\text{ は気圧 }\rho(h)\text{ に依存しない}
}
\]

ことである。

したがって、

- 海面高度
- 高高度
- 低気圧領域

のいずれでも、砲弾固有の速度減衰そのものは同じ係数で作用する。

この点は通常の実世界の空気抵抗とは大きく異なる。

### 5.1 連続時間の線形減衰モデル

弾速減衰を連続時間の線形モデルとして表す場合、

\[
\boxed{
\frac{d\mathbf v}{dt}
=
-K\mathbf v
}
\]

となる。

外力が無ければ、

\[
\boxed{
\mathbf v(t)=\mathbf v_0e^{-Kt}
}
\]

である。

したがって速度方向は変化せず、速度の大きさだけが指数関数的に減衰する。

### 5.2 1 tick ごとの減速率として与えられる場合

もしゲーム上の減速率を「1 tick 後に速度が \((1-d)\) 倍になる」離散係数 \(d\) として扱う場合、対応する連続減衰係数 \(K_c\) は、

\[
\boxed{
K_c=-\ln(1-d)
}
\]

である。

どちらの \(K\) を使用しているかは実装上区別する必要がある。

---

## 6. 風による加速度

風速度の大きさを

\[
V_w=|\mathbf V_w|
\]

砲弾固有の風影響係数を

\[
C_w
\]

とする。

風による加速度の大きさは、

\[
\boxed{
a_w
=
\rho(h)V_wC_w
}
\]

である。

ベクトルとして書けば、

\[
\boxed{
\mathbf a_w(h)
=
\rho(h)C_w\mathbf V_w
}
\]

となる。

成分表示では、

\[
a_{wx}
=
\rho(h)C_wV_{wx}
\]

\[
a_{wy}
=
\rho(h)C_wV_{wy}
\]

\[
\boxed{
a_{wz}=0
}
\]

である。

---

## 7. 風の特徴

Stormworks の風影響には、砲弾固有の速度減衰とは異なる重要な特徴がある。

### 7.1 高度依存

風速度 \(\mathbf V_w\) 自体が一定でも、

\[
\mathbf a_w(h)
=
\rho(h)C_w\mathbf V_w
\]

なので、高度が上昇して気圧が下がるほど風の影響は小さくなる。

したがって、高角弾道では、

- 上昇中に風影響が弱くなる
- 頂点付近ではさらに弱くなる
- 下降して低高度へ戻ると再び強くなる

という非一様な横加速度を受ける。

### 7.2 風は水平のみ

\[
V_{wz}=0
\]

なので、風が直接弾丸を上下方向へ押すことはない。

ただし、風によって水平軌道が変化し、その結果として飛翔時間や高度履歴が変化すれば、重力や気圧の受け方も間接的に変化する。

---

## 8. 重力と風を合わせた外力

砲弾に作用する、速度減衰以外の加速度ベクトルは、

\[
\mathbf a(h)
=
\mathbf a_w(h)+\mathbf g(h)
\]

したがって、

\[
\boxed{
\mathbf a(h)
=
\begin{pmatrix}
\rho(h)C_wV_{wx}\\
\rho(h)C_wV_{wy}\\
-g(h)
\end{pmatrix}
}
\]

となる。

具体的には、

\[
\boxed{
\mathbf a(h)
=
\begin{pmatrix}
\rho(h)C_wV_{wx}\\
\rho(h)C_wV_{wy}\\
-30e^{-h/60000}
\end{pmatrix}
}
\]

である。

---

## 9. 砲弾の運動方程式

線形速度減衰と高度依存外力をまとめると、砲弾速度 \(\mathbf v\) の運動方程式は、

\[
\boxed{
\frac{d\mathbf v}{dt}
=
-K\mathbf v
+
\begin{pmatrix}
\rho(h)C_wV_{wx}\\
\rho(h)C_wV_{wy}\\
-30e^{-h/60000}
\end{pmatrix}
}
\]

位置については、

\[
\boxed{
\frac{d\mathbf r}{dt}=\mathbf v
}
\]

である。

ここで、

\[
h=r_z
\]

である。

したがって完全な状態方程式は、

\[
\boxed{
\begin{cases}
\dot x=v_x\\
\dot y=v_y\\
\dot z=v_z\\
\dot v_x=-Kv_x+\rho(z)C_wV_{wx}\\
\dot v_y=-Kv_y+\rho(z)C_wV_{wy}\\
\dot v_z=-Kv_z-g(z)
\end{cases}
}
\]

となる。

---

## 10. 各軸の特徴

### 10.1 X 軸

\[
\dot v_x
=
-Kv_x+\rho(h)C_wV_{wx}
\]

速度減衰と風加速度だけを受ける。

### 10.2 Y 軸

\[
\dot v_y
=
-Kv_y+\rho(h)C_wV_{wy}
\]

X 軸と同様である。

### 10.3 Z 軸

\[
\dot v_z
=
-Kv_z-g(h)
\]

風の直接影響を受けず、

- 速度減衰
- 高度依存重力

だけを受ける。

---

## 11. Stormworks 砲弾運動の重要な構造

### 11.1 速度減衰は高度非依存

\[
K=\mathrm{const.}
\]

であり、

\[
K\neq K(\rho)
\]

である。

つまり、高高度になって気圧が低下しても弾丸の固有減速は弱くならない。

### 11.2 重力のみ高度依存

\[
g=g(h)
\]

であり、高高度になるほど鉛直下向き加速度が弱くなる。

### 11.3 風影響は気圧依存

\[
a_w\propto\rho(h)
\]

である。

したがって高高度では風の影響が弱くなる。

### 11.4 風は横方向だけ

\[
V_{wz}=0
\]

なので、風の直接効果は水平2軸に限定される。

### 11.5 非線形性は主に高度依存環境から生じる

速度減衰項自体は、

\[
-K\mathbf v
\]

という線形項である。

しかし、

\[
g=g(h)
\]

\[
\rho=\rho(h)
\]

であり、高度 \(h\) 自体が軌道の結果なので、運動方程式全体としては状態依存の非線形系になる。

---

## 12. 一定高度環境での局所解析解

短い区間内で高度変化を無視し、

\[
g(h)\approx g_i
\]

\[
\rho(h)\approx\rho_i
\]

と一定とみなす。

すると加速度ベクトルも一定となり、

\[
\mathbf a_i=
\begin{pmatrix}
\rho_iC_wV_{wx}\\
\rho_iC_wV_{wy}\\
-g_i
\end{pmatrix}
\]

運動方程式は、

\[
\dot{\mathbf v}
=
-K\mathbf v+\mathbf a_i
\]

となる。

この区間内では解析解を使用できる。

速度:

\[
\boxed{
\mathbf v(t)
=
\left(
\mathbf v_0-\frac{\mathbf a_i}{K}
\right)e^{-Kt}
+
\frac{\mathbf a_i}{K}
}
\]

位置:

\[
\boxed{
\mathbf r(t)
=
\mathbf r_0+
\frac{
\left(
\mathbf v_0-\mathbf a_i/K
\right)
(1-e^{-Kt})
+
\mathbf a_it
}{K}
}
\]

となる。

Ballistic Calculator V5 は、この性質を利用して各区間を解析解で進め、区間ごとに代表高度から \(g\) と \(\rho\) を更新する方式に近い。fileciteturn11file2

## 13. なぜ数値積分または区分解析積分が必要になるか

完全な Stormworks モデルでは、

\[
g=g(h)
\]

\[
\rho=\rho(h)
\]

である。

したがって、弾丸が上昇・下降すると、その瞬間ごとに

\[
g
\]

と

\[
\mathbf a_w
\]

が変化する。

そのため弾道全体を1組の一定係数だけで厳密に表すことはできない。

高精度化する方法としては、

1. 軌道を複数区間へ分割する
2. 各区間の代表高度を求める
3. その高度で \(g(h)\) と \(\rho(h)\) を評価する
4. 区間内を減衰あり等加速度運動の解析解で進める
5. 次区間で環境を更新する

という piecewise analytic integration が有効である。fileciteturn11file0

## 14. 秋雨弾道計算機との関係

秋雨弾道計算機 `test10.lua` は、弾道全体の平均高度 \(\bar h\) を解析的に求め、

\[
g_{\mathrm{eff}}=g(\bar h)
\]

\[
\rho_{\mathrm{eff}}\approx\rho(\bar h)
\]

として、弾道全体を代表環境で近似する。fileciteturn11file1

一方、V5 は複数区間に分けて局所的に、

\[
g_i=g(\bar h_i)
\]

\[
\rho_i=\rho(\bar h_i)
\]

を更新する。

したがって両者の違いは、

- 秋雨方式: 弾道全体を1つの代表環境で扱う
- V5方式: 弾道を複数区間に分け、局所環境を更新する

という点にある。fileciteturn11file0

## 15. 弾道計算上の重要な注意点

### 15.1 平均高度の気圧と平均気圧は一致しない

一般に、

\[
\boxed{
\rho\left(
\frac1T\int_0^T h(t)\,dt
\right)
\neq
\frac1T\int_0^T\rho(h(t))\,dt
}
\]

である。

気圧は高度に対して非線形なので、平均高度へ気圧式を代入する方法は近似になる。

### 15.2 重力も同様

\[
g(h)=30e^{-h/60000}
\]

は非線形なので、

\[
g(\bar h)
\]

と軌道全体の平均重力は厳密には一致しない。

### 15.3 風の着弾偏差は単純な平均気圧だけでは決まらない

風加速度が早い時刻に作用した場合、その後長い時間だけ横速度として影響が蓄積する。

したがって、着弾位置への風影響を高精度に近似する場合は、単純な時間平均気圧よりも、時間位置によって重み付けされた実効気圧の方が適切になる可能性がある。fileciteturn11file0

|---|---:|---|
| 砲弾固有減速率 | なし | \(K=\mathrm{const.}\) |
| 重力加速度 | あり | \(g(h)=30e^{-h/60000}\) |
| 気圧 | あり | \(\rho(h)=(((44.33-h/1000)/11.89)^{5.256})/1013\) |
| 風速度の Z 成分 | 常に 0 | \(V_{wz}=0\) |
| 風加速度 | あり | \(\mathbf a_w=\rho(h)C_w\mathbf V_w\) |

## 17. 最終的な運動モデル

Stormworks の通常砲弾について、今回整理した物理モデルは、

\[
\boxed{
\dot{\mathbf r}=\mathbf v
}
\]

\[
\boxed{
\dot{\mathbf v}
=
-K\mathbf v
+
\rho(h)C_w\mathbf V_w
+
\begin{pmatrix}
0\\
0\\
-g(h)
\end{pmatrix}
}
\]

ただし、

\[
\boxed{
g(h)=30e^{-h/60000}
}
\]

\[
\boxed{
\rho(h)=
\frac{
\left(
\frac{44.33-h/1000}{11.89}
\right)^{5.256}
}{
1013
}
}
\]

\[
\boxed{
\mathbf V_w=
\begin{pmatrix}
V_{wx}\\
V_{wy}\\
0
\end{pmatrix}
}
\]

で表される。

このモデルの最大の特徴は、

\[
\boxed{
\text{減速率 }K\text{ は高度・気圧に依存しない}
}
\]

一方で、

\[
\boxed{
\text{重力と風影響は高度によって変化する}
}
\]

ことである。

そのため、Stormworks の高精度弾道計算では、速度減衰そのものよりも、**軌道に沿って変化する重力 \(g(h)\) と気圧 \(\rho(h)\) をどのように評価・積分するか**が主要な精度要因となる。
