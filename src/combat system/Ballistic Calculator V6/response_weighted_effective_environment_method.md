# Stormworks 1次元弾道計算における応答重み付き実効重力・実効気圧

更新日: 2026-08-19

## 1. 目的

Stormworks の弾道計算を、仰角・方位角の多変数探索ではなく、飛翔時間 \(T\) の1次元探索として維持したまま、

- 高度依存重力加速度
- 高度依存気圧
- 風による高度依存加速度

を高精度に取り込む方法を整理する。

これまでの候補には、弾道全体の時間平均高度

\[
\bar h=\frac1T\int_0^T h(t)\,dt
\]

を求め、

\[
g_{\mathrm{eff}}=g(\bar h)
\]

\[
\rho_{\mathrm{eff}}=\rho(\bar h)
\]

とする方式があった。

この方法は非常に高精度で軽量だが、

\[
g\left(\frac1T\int h\,dt\right)
\neq
\frac1T\int g(h(t))\,dt
\]

\[
\rho\left(\frac1T\int h\,dt\right)
\neq
\frac1T\int \rho(h(t))\,dt
\]

であるため、厳密には近似である。

さらに、着弾位置への加速度の影響は時刻によって異なるため、単純な時間平均そのものも最適な代表値ではない。

本メモでは、この問題を「着弾位置への応答重み付き平均」により解決する。

---

## 2. Stormworks の高度依存環境

高度を \(h\) [m] とする。

### 2.1 重力加速度

\[
\boxed{
g(h)=30e^{-h/60000}
}
\]

### 2.2 気圧係数

\[
\boxed{
\rho(h)=
\frac{
\left(
\frac{44.33-h/1000}{11.89}
\right)^{5.256}
}{
1013
}
}
\]

### 2.3 風加速度

風ベクトルを

\[
\mathbf V_w=
\begin{pmatrix}
V_{wx}\\
V_{wy}\\
0
\end{pmatrix}
\]

砲弾固有の風影響係数を \(C_w\) とすれば、

\[
\boxed{
\mathbf a_w(h)=\rho(h)C_w\mathbf V_w
}
\]

となる。

砲弾固有の速度減衰率 \(k\) は高度・気圧に依存しない。

## 3. 一定環境での1次元解析弾道

一定の重力・気圧を仮定したとき、線形減衰系では

\[
L(t)=\frac{1-e^{-kt}}{k}
\]

\[
M(t)=
\frac{t}{k}
-
\frac{1-e^{-kt}}{k^2}
\]

を定義できる。

一定外力 \(\mathbf A_B\) に対する弾丸位置は、

\[
\boxed{
\mathbf r_B(t)
=
V L(t)\mathbf n
+
M(t)\mathbf A_B
}
\]

となる。

一定環境なら、飛翔時間 \(T\) を固定したとき初速度方向 \(\mathbf n\) を解析的に逆算できるため、

\[
F(T)=0
\]

という飛翔時間1変数の求根問題へ縮約できる。

この1次元構造は、新方式でも維持する。

---

## 4. 任意時刻の高度を解析的に求める

仮の実効重力を \(g_e\) とする。

初期高度を \(h_0\)、初速度の鉛直成分を \(v_{0z}\) とすれば、

\[
\boxed{
h(t)
=
h_0
+
v_{0z}L(t)
-
g_eM(t)
}
\]

で任意時刻の高度を直接計算できる。

重要なのは、途中の時刻を順番に積分する必要がないことである。

したがって、

\[
t
\rightarrow
h(t)
\rightarrow
g(h(t)),\rho(h(t))
\]

という経路を解析軌道上で直接評価できる。

---

## 5. なぜ単純な時間平均では不十分なのか

単純時間平均重力は、

\[
\bar g
=
\frac1T
\int_0^T
g(h(t))\,dt
\]

である。

しかし、時刻 \(t\) に受けた加速度が着弾位置へ与える影響は、時刻によって異なる。

発射直後に加速度を受けた場合、その結果生じた速度変化は、その後長時間にわたり位置へ影響する。

一方、着弾直前に同じ加速度を受けても、位置を変化させる残り時間はほとんどない。

したがって、全時刻を同じ重みで平均するのは、着弾位置を再現する目的では最適ではない。

---

## 6. 着弾位置への応答重み

時刻 \(t\) に、短時間だけ加速度が作用し、速度が \(\Delta v\) 変化したとする。

その速度変化は線形減衰により、その後

\[
\Delta v(\tau)
=
\Delta v e^{-k(\tau-t)}
\]

と減衰する。

着弾時刻 \(T\) までに生じる位置変化は、

\[
\Delta x(T)
=
\int_t^T
\Delta v e^{-k(\tau-t)}
\,d\tau
\]

となる。

積分すると、

\[
\Delta x(T)
=
\Delta v
\frac{1-e^{-k(T-t)}}{k}
\]

すなわち、

\[
\boxed{
\Delta x(T)=\Delta v L(T-t)
}
\]

である。

したがって、

\[
\boxed{
w(t)=L(T-t)
}
\]

は、

「時刻 \(t\) に生じた速度変化が、最終着弾位置へどれだけ効くか」

を表す応答重みとなる。

---

## 7. 応答重みの性質

\[
w(t)=
\frac{1-e^{-k(T-t)}}{k}
\]

である。

1階微分は、

\[
w'(t)
=
-e^{-k(T-t)}
<0
\]

なので、飛翔時刻が進むほど単調減少する。

2階微分は、

\[
w''(t)
=
-k e^{-k(T-t)}
<0
\]

なので凹関数である。

抗力ゼロ極限では、

\[
k\rightarrow0
\]

に対して、

\[
\boxed{
w(t)\rightarrow T-t
}
\]

となり、単純な直線重みになる。

---

## 8. 応答重み付き実効重力

着弾位置への寄与を正しく平均するには、

\[
\boxed{
g_e
=
\frac{
\displaystyle
\int_0^T
L(T-t)g(h(t))\,dt
}{
\displaystyle
\int_0^T
L(T-t)\,dt
}
}
\]

とする。

分母は、

\[
\int_0^T L(T-t)\,dt
\]

である。

変数変換により、

\[
\int_0^T L(T-t)\,dt
=
\int_0^T L(\tau)\,d\tau
\]

となり、

\[
\boxed{
\int_0^T L(T-t)\,dt=M(T)
}
\]

である。

したがって、

\[
\boxed{
g_e
=
\frac{
\displaystyle
\int_0^T
L(T-t)g(h(t))\,dt
}{
M(T)
}
}
\]

となる。

\(M(T)\) が現れるのは偶然ではない。

\(L\) が「速度変化から位置変化への応答」であり、\(M\) はその応答を時間方向へ積分した「一定加速度から位置変化への応答」だからである。

---

## 9. 応答重み付き実効気圧

Stormworks の風加速度は、

\[
\mathbf a_w(t)
=
\rho(h(t))C_w\mathbf V_w
\]

である。

風ベクトル \(\mathbf V_w\) と \(C_w\) が飛翔中一定なら、\(C_w\mathbf V_w\) は積分の外へ出せる。

したがって、実際の高度依存風加速度と同じ着弾偏差を与える一定気圧 \(\rho_e\) は、

\[
\boxed{
\rho_e
=
\frac{
\displaystyle
\int_0^T
L(T-t)\rho(h(t))\,dt
}{
M(T)
}
}
\]

となる。

つまり重力と気圧は、完全に同じ応答重み

\[
\boxed{
w(t)=L(T-t)
}
\]

を共有できる。

---

## 10. 単純時間平均が高精度だった理由

時間平均高度または時間平均環境が実用上かなり高精度だったのには複数の理由がある。

### 10.1 上昇・下降弾道の時間対称性

発射高度と着弾高度が近い通常弾道では、

\[
h(t)\approx h(T-t)
\]

となる。

抗力が弱く、

\[
w(t)\approx T-t
\]

なら、対称な環境履歴 \(a(t)=a(T-t)\) に対して、

\[
\frac{
\int_0^T
(T-t)a(t)\,dt
}{
\int_0^T
(T-t)\,dt
}
=
\frac1T
\int_0^T
a(t)\,dt
\]

が成立する。

したがって、時間平均と応答重み付き平均が一致しやすい。

### 10.2 線形減衰による重みの平坦化

\[
L(T-t)
=
\frac{1-e^{-k(T-t)}}{k}
\]

は、残り時間が長くなるほど \(1/k\) に飽和する。

そのため抗力が強い場合は、飛翔前半〜中盤の重みが比較的平坦になり、単純時間平均へ近づく。

### 10.3 平均高度への代入誤差は一次項が消える

高度を、

\[
h(t)=\bar h+\delta h(t)
\]

とし、

\[
\overline{\delta h}=0
\]

とする。

例えば重力をTaylor展開すると、

\[
g(h)
=
g(\bar h)
+
g'(\bar h)\delta h
+
\frac12g''(\bar h)\delta h^2
+\cdots
\]

時間平均時に一次項が消えるため、

\[
\bar g-g(\bar h)
\]

は高度変動に対して二次以上の誤差になる。

### 10.4 気圧は弾速減衰には入らない

Stormworks では気圧は風加速度だけに作用し、弾丸固有減衰 \(k\) は気圧非依存である。

したがって無風時には、気圧近似誤差そのものが弾道へ現れない。

### 10.5 1次元ソルバーが一部のモデル誤差を吸収する

代表環境が多少ずれていても、飛翔時間 \(T\) と発射方向がその近似モデル内で再最適化される。

このため環境係数の誤差が、そのまま着弾誤差になるわけではない。

---

## 11. 時間平均が弱くなる代表例

高度3 kmから、水平より45°下向きに対地攻撃するような弾道では、

- 初期: 高高度
- 終末: 低高度

となり、高度履歴の時間対称性がない。

この場合、

- 初期の弱い重力・低い気圧
- 終末の強い重力・高い気圧

を単純時間平均すると、終末環境を着弾位置に対して過大評価しやすい。

実際の着弾位置への寄与は飛翔前半ほど大きいため、応答重み付き平均では実効環境が高高度側へ寄る。

したがって、

\[
\boxed{
\text{高度差が大きい}
+
\text{単調な上昇・下降}
}
\]

ほど、単純時間平均との差が出やすい。

特に気圧は高度非線形性が強いため、強風条件で影響が大きくなる可能性がある。

---

## 12. 真の数値積分との関係

時間変化する外力 \(\mathbf A(t)\) に対する終点位置は、

\[
\mathbf r(T)
=
V L(T)\mathbf n
+
\int_0^T
L(T-t)\mathbf A(t)\,dt
\]

と書ける。

したがって、真の高度履歴 \(h_{\mathrm{true}}(t)\) が既知であれば、

\[
g_e
=
\frac{
\int_0^T
L(T-t)g(h_{\mathrm{true}}(t))\,dt
}{
M(T)
}
\]

を使った一定実効重力は、終点位置に関して元の高度依存重力と厳密に等価である。

つまり、

\[
\boxed{
\text{応答重み付き平均そのものは、終点位置について近似ではない}
}
\]

近似誤差が発生するのは、\(h_{\mathrm{true}}(t)\) を知らないため、

\[
h(t)
=
h_0+v_{0z}L(t)-g_eM(t)
\]

という一定実効重力による解析近似軌道を用いて実効環境を評価する部分である。

この近似軌道を自己整合反復させることで、真の軌道へ接近させる。

---

## 13. 数値求積による実効環境評価

分子、

\[
I_g=
\int_0^T
L(T-t)g(h(t))\,dt
\]

\[
I_\rho=
\int_0^T
L(T-t)\rho(h(t))\,dt
\]

は、初等関数だけで簡単に解析積分することが難しい。

そのため、少数点の数値求積が有力候補となる。

重要なのは、

「弾道そのものを数値積分する」

のではなく、

「解析的に求められる軌道上で、定積分だけを数値求積する」

ことである。

したがって1次元探索構造は維持される。

---

## 14. 3点Gauss–Legendre求積

区間、

\[
0\le t\le T
\]

について、3点Gauss–Legendreでは次の3時刻を評価する。

\[
t_1
=
\frac{T}{2}
\left(
1-\sqrt{\frac35}
\right)
\]

\[
t_2=\frac{T}{2}
\]

\[
t_3
=
\frac{T}{2}
\left(
1+\sqrt{\frac35}
\right)
\]

数値では、

\[
\frac{t_1}{T}\approx0.112701665
\]

\[
\frac{t_2}{T}=0.5
\]

\[
\frac{t_3}{T}\approx0.887298335
\]

である。

積分係数は、

\[
q_1=q_3=\frac5{18}
\]

\[
q_2=\frac49
\]

となる。

任意関数 \(f(t)\) に対して、

\[
\int_0^T f(t)\,dt
\approx
T
\left[
\frac5{18}f(t_1)
+
\frac49f(t_2)
+
\frac5{18}f(t_3)
\right]
\]

と近似する。

3点Gauss–Legendreは5次多項式まで厳密に積分できる。

---

## 15. 重力への3点Gauss求積の適用

各評価点について、

\[
h_i
=
h_0
+
v_{0z}L(t_i)
-
g_eM(t_i)
\]

を計算する。

その高度から、

\[
g_i=g(h_i)
\]

さらに応答重み、

\[
W_i=L(T-t_i)
\]

を計算する。

すると、

\[
\boxed{
I_g
\approx
T
\left[
\frac5{18}W_1g_1
+
\frac49W_2g_2
+
\frac5{18}W_3g_3
\right]
}
\]

したがって、

\[
\boxed{
g_e
\approx
\frac{
T
\left[
\frac5{18}W_1g_1
+
\frac49W_2g_2
+
\frac5{18}W_3g_3
\right]
}{
M(T)
}
}
\]

となる。

---

## 16. 気圧への3点Gauss求積の適用

同じ3つの高度、\(h_1,h_2,h_3\) をそのまま使う。

\[
\rho_i=\rho(h_i)
\]

とすれば、

\[
\boxed{
I_\rho
\approx
T
\left[
\frac5{18}W_1\rho_1
+
\frac49W_2\rho_2
+
\frac5{18}W_3\rho_3
\right]
}
\]

したがって、

\[
\boxed{
\rho_e
\approx
\frac{
T
\left[
\frac5{18}W_1\rho_1
+
\frac49W_2\rho_2
+
\frac5{18}W_3\rho_3
\right]
}{
M(T)
}
}
\]

となる。

重力・気圧で、評価時刻・高度・応答重みをすべて共有できる。

## 17. Gauss求積の意味

3点Gauss求積は、

「3ステップで弾道を数値積分している」

わけではない。

弾道自体は、

\[
h(t)
=
h_0+v_{0z}L(t)-g_eM(t)
\]

という解析式で求める。

Gauss求積では、\(t_1,t_2,t_3\) の3地点を解析式から直接評価し、

\[
f(t)=L(T-t)g(h(t))
\]

または、

\[
f(t)=L(T-t)\rho(h(t))
\]

の定積分だけを少数点で近似する。

したがって、

\[
\boxed{
\text{解析弾道}
+
\text{少数点数値求積}
}
\]

という構成になる。

## 18. 自己整合反復

初期値として仮の、

\[
g_e^{(0)},\rho_e^{(0)}
\]

を与える。

この環境で1次元弾道方程式、

\[
F(T)=0
\]

を解き、

\[
T^{(n)},\mathbf n^{(n)}
\]

を得る。

その発射方向から \(v_{0z}^{(n)}\) を得る。

次に、

\[
h^{(n)}(t)
=
h_0
+
v_{0z}^{(n)}L(t)
-
g_e^{(n)}M(t)
\]

を使って応答重み付き平均を求め、

\[
g_e^{(n+1)},\rho_e^{(n+1)}
\]

へ更新する。

全体は、

\[
(g_e^{(n)},\rho_e^{(n)})
\rightarrow
F(T)=0
\rightarrow
T^{(n)},\mathbf n^{(n)}
\rightarrow
h^{(n)}(t)
\rightarrow
(g_e^{(n+1)},\rho_e^{(n+1)})
\]

という固定点反復になる。

必要であれば、

\[
g_e
\leftarrow
\frac{
g_e+g_e^{\mathrm{new}}
}{2}
\]

\[
\rho_e
\leftarrow
\frac{
\rho_e+\rho_e^{\mathrm{new}}
}{2}
\]

のようなアンダーリラクゼーションも候補となる。

# 19. 後で吟味すべき事項

以下は、今回の議論中に保留した比較・最適化候補である。

## 19.1 2点・3点・4点Gauss求積の比較

Gauss–Legendre求積は、\(n\) 点なら \(2n-1\) 次多項式まで厳密である。

候補:

- 1点: 1次まで厳密
- 2点: 3次まで厳密
- 3点: 5次まで厳密
- 4点: 7次まで厳密

Stormworks の \(g(h)\) は比較的滑らかだが、\(\rho(h)\) はより強い非線形性を持つ。

したがって必要評価点数は、重力よりも気圧側が決める可能性が高い。

今後、2点・3点・4点を高精度数値積分による真値と比較し、

- 着弾誤差
- 計算時間
- Lua文字数

の最適点を探る必要がある。

---

## 19.2 部分積分してから残差だけ数値求積する方法

重力分子、

\[
I_g
=
\int_0^T
L(T-t)g(h(t))\,dt
\]

について、

\[
u=g(h(t))
\]

\[
dv=L(T-t)\,dt
\]

として部分積分すると、

\[
\boxed{
I_g
=
g(h_0)M(T)
+
\int_0^T
M(T-t)
\frac{d}{dt}g(h(t))
\,dt
}
\]

となる。

Stormworks の重力式では、

\[
\frac{dg}{dh}
=
-\frac{g(h)}{60000}
\]

かつ、

\[
\frac{dh}{dt}=v_z(t)
\]

なので、

\[
\boxed{
I_g
=
g(h_0)M(T)
-
\frac1{60000}
\int_0^T
M(T-t)g(h(t))v_z(t)\,dt
}
\]

となる。

したがって、

\[
\boxed{
g_e
=
g(h_0)
-
\frac{
\displaystyle
\int_0^T
M(T-t)g(h(t))v_z(t)\,dt
}{
60000M(T)
}
}
\]

となる。

### 利点候補

- 大きな基準項 \(g(h_0)M(T)\) が解析化される
- 高度変化が小さい場合、残差積分自体が小さくなる
- 少ない求積点で高精度になる可能性がある

### 欠点候補

高角弾道では \(v_z(t)\) が頂点で符号反転する。

そのため残差積分に正負キャンセルが生じ、数値的にかえって扱いづらくなる可能性がある。

元の \(L(T-t)g(h(t))\) は常に滑らかで正なので、Gauss求積との相性はこちらの方が良い可能性もある。

したがって、

\[
\boxed{
\text{直接求積}
\quad\text{vs}\quad
\text{部分積分後の残差求積}
}
\]

は今後比較する価値がある。

## 19.3 分子の完全解析積分

重力分子について、

\[
h(t)
=
h_0
+
A(1-e^{-kt})
-
Bt
\]

と整理できる。

重力式へ代入すると、\(g(h(t))\) には概ね、

\[
e^{\alpha t+\beta e^{-kt}}
\]

という形が現れる。

さらに、

\[
u=e^{-kt}
\]

と置換すると、

\[
\int u^p e^{\beta u}\,du
\]

のような形へ変形可能であり、特殊関数を許せば解析表現できる可能性が高い。

ただし、

- 不完全ガンマ関数などの特殊関数が必要
- Stormworks Lua で自前実装する価値が低い
- 文字数・演算量ともに増える可能性が高い

ため、実装候補としての優先度は未評価。

---

## 19.4 \(g(h),\rho(h)\) を近似して解析積分する方法

高度範囲内で、

\[
g(h)
\approx
a_0+a_1h+a_2h^2+\cdots
\]

\[
\rho(h)
\approx
b_0+b_1h+b_2h^2+\cdots
\]

と低次多項式近似する案。

解析軌道は、

\[
h(t)
=
C_0+C_1t+C_2e^{-kt}
\]

という形なので、低次多項式へ代入・展開すれば、

\[
t^m e^{-nkt}
\]

の和にできる。

これらは初等関数だけで解析積分可能。

### 評価すべき点

- 元の環境式を3回評価するGauss求積より軽いか
- 多項式近似誤差はどの程度か
- 高高度まで1本の近似式で対応できるか
- 区分近似が必要になるか
- Lua文字数が本当に減るか

現時点では、3点Gauss求積の方が実装は単純。

## 19.5 応答重み専用Gaussian quadrature

通常のGauss–Legendreは、

\[
\int f(t)\,dt
\]

に対して評価点と係数を最適化する。

しかし今回の積分には最初から、

\[
L(T-t)
\]

という既知の重み関数が含まれている。

したがって、

\[
\int_0^T
L(T-t)f(t)\,dt
\]

専用のGaussian quadratureを構築すれば、

\[
g_e
\approx
a_1g(h(t_1))
+
a_2g(h(t_2))
+\cdots
\]

のように、応答重みそのものを求積係数へ吸収できる可能性がある。

これにより、

- 評価点数削減
- \(L(T-t_i)\) の演算削減
- 高精度化

が期待できる。

ただし評価点・係数が \(kT\) に依存する可能性があり、実装の単純さとの比較が必要。

## 19.6 自己整合反復の更新方法

候補は直接更新とアンダーリラクゼーション。

### 直接更新

\[
g_e^{(n+1)}=g_{e,\mathrm{new}}
\]

\[
\rho_e^{(n+1)}=\rho_{e,\mathrm{new}}
\]

最も軽い。

### アンダーリラクゼーション

\[
g_e^{(n+1)}
=
(1-\lambda)g_e^{(n)}
+
\lambda g_{e,\mathrm{new}}
\]

\[
\rho_e^{(n+1)}
=
(1-\lambda)\rho_e^{(n)}
+
\lambda\rho_{e,\mathrm{new}}
\]

例えば \(\lambda=0.5\) とする。

収束安定性は向上する可能性があるが、反復回数が増える可能性がある。

今後、

- 直接更新で十分か
- 高角・高高度・強風条件で振動するか
- 秋雨方式のような \(1/2\) 更新が必要か

を確認する。

## 19.7 初期実効環境のシード

候補:

1. 発射高度そのもの

\[
g_e^{(0)}=g(h_0)
\]

\[
\rho_e^{(0)}=\rho(h_0)
\]

2. 目標高度との単純平均高度
3. 秋雨方式の解析時間平均高度
4. 前tickの弾道解から得た \(g_e,\rho_e\)

リアルタイムFCSでは、前tickの解をシードとして使えば反復回数を大幅に減らせる可能性がある。

## 19.8 数値積分へは戻さない

Gauss求積は複合化すれば高精度ODE積分にも応用できる。

しかし本方式の最大の目的は、

\[
\boxed{
\text{飛翔時間 }T\text{ の1次元探索構造を維持すること}
}
\]

である。

弾道そのものを逐次数値積分すると、

\[
T\rightarrow\mathbf v_0(T)
\]

を解析的に逆算できる構造が失われ、仰角・方位角の多変数探索へ戻る可能性がある。

したがって本開発では、

\[
\boxed{
\text{弾道数値積分には戻らない}
}
\]

ことを基本方針とする。

Gauss求積は、

\[
\boxed{
\text{解析弾道上の環境積分だけに使用する}
}
\]

# 20. 現時点の最有力アルゴリズム

### Step 1

仮の \(g_e,\rho_e\) を設定。

### Step 2

一定環境として、

\[
F(T)=0
\]

をBrent法などで1次元求根。

### Step 3

得られた \(T\) から発射方向を解析的に逆算し、\(v_{0z}\) を得る。

### Step 4

Gauss評価時刻 \(t_i\) で、

\[
h_i
=
h_0+v_{0z}L(t_i)-g_eM(t_i)
\]

を計算。

### Step 5

各高度で、

\[
g_i=g(h_i)
\]

\[
\rho_i=\rho(h_i)
\]

を評価。

### Step 6

応答重み \(W_i=L(T-t_i)\) を使用してGauss求積。

### Step 7

\[
g_e^{\mathrm{new}}
\]

\[
\rho_e^{\mathrm{new}}
\]

を求める。

### Step 8

環境値が収束するまで反復。

# 21. 一言まとめ

秋雨方式は、

\[
\boxed{
\text{弾道全体}
\rightarrow
\text{時間平均高度1個}
\rightarrow
g(\bar h),\rho(\bar h)
}
\]

であった。

新方式は、

\[
\boxed{
\text{解析弾道}
\rightarrow
\text{着弾位置への応答重み}
\rightarrow
\text{実効 }g,\rho
}
\]

である。

その本質は、

\[
\boxed{
g_e
=
\frac{
\int_0^T
L(T-t)g(h(t))dt
}{
M(T)
}
}
\]

\[
\boxed{
\rho_e
=
\frac{
\int_0^T
L(T-t)\rho(h(t))dt
}{
M(T)
}
}
\]

にある。

これにより、

- 高度依存環境を考慮
- 1次元飛翔時間探索を維持
- 弾道数値積分不要
- 数点の環境評価だけで高精度化可能
- 上昇・下降非対称弾道でも時間平均より自然
- 真の軌道が既知なら終点位置について数値積分と等価

という構造が得られる。

現時点の最重要な比較課題は、

\[
\boxed{
\text{2点GL}
\quad\text{vs}\quad
\text{3点GL}
\quad\text{vs}\quad
\text{部分積分＋少数点求積}
}
\]

であり、そこから精度・速度・文字数の最適点を決定する。
